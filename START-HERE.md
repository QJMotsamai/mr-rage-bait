# Start here (slow version)

You do not need to understand all of this at once.
Do **one numbered step**, then stop, then do the next one.

There are only 4 jobs:

1. Get this zip onto your computer
2. Put the files on GitHub
3. Create a free Paystack account (payments)
4. Put the app on Render (free hosting)

The **admin board** is a secret page only you can open.
It is not a normal user login.

---

## Words you will see

| Word | Meaning |
| --- | --- |
| GitHub | A website that stores your code |
| Render | A website that turns the code into a live app |
| Paystack | A website that takes card payments for you |
| Environment variable | A secret you type into Render. Not a file on GitHub |
| ADMIN_KEY | A password **you invent** for the secret `/admin` page |
| User account | What a visitor creates with email + password in the chat |
